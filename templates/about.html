About This Project

TruthLens is a fake news detection demo built for educational and presentation use. It combines a supervised NLP classifier with a lightweight evidence signal to show how textual patterns and external context can support credibility analysis.

Model Layer

TF-IDF features with a PassiveAggressive classifier trained on labeled real/fake news examples.

Fact Signal Layer

Retrieves external evidence snippets and compares semantic similarity with the submitted claim.

Current Scope

Designed as a demonstration system. Results should be treated as indicators, not final truth judgments.

This project is open source and available on GitHub for learning and experimentation: GitHub Repository
